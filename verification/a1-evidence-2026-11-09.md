### 6.2 Browser preview authentication — known limitation, NOT solved

The preview gate is a bearer header (`Authorization: Bearer $ACE_PREVIEW_TOKEN`) by design, and a
browser cannot attach that header to a top-level navigation. All of the following remain true:

* opening `/review/<slug>` in a browser tab returns **404** (observed for both the page and its `<img>`);
* the `data:` URI change only keeps the **already-authenticated HTML response** free of broken images;
  it does **not** make the page reachable by URL in a browser;
* the screenshots in this record come from a snapshot that **bypasses the gate**, so they are
  evidence of rendering and content, not of authenticated navigation.

No navigation-authentication mechanism (cookie session, signed URL, query-string token) was added,
and **no fix is claimed**. Any such mechanism changes the security model and therefore needs its own
decision; it is explicitly outside A1.

### 6.3 Pending Owner decision — hero crop

`.hero img` uses `object-fit: cover`. Measured at 375 px the hero box is **329 × 420** (ratio 0.78)
while the source frame is 1080 × 1920 (ratio 0.5625), so the frame is cropped top and bottom and its
in-frame headline is partly cut. Switching to `contain` or an `aspect-ratio` box would show the whole
frame.
**Not changed** — recorded here for the Owner to decide.

## 7. Known limitations / open items

1. **Browser preview is not usable via navigation URL** — header-only gate, documented in §6.2 and not solved in A1. Local viewing needs an HTTP client that can set the header, or the snapshot method used in §6.
2. **Desktop verified numerically only** — no representative 1280 px screenshot exists.
3. **Hero crop awaiting Owner decision** (§6.3): measured 329 × 420 at 375 px against a 1080 × 1920 source.
4. `403 LOOPBACK_ONLY` could not be exercised from an off-loopback origin; only the address-set check is verified.
5. Prose length is template-bound: editing the Thai connective copy in `app/site/article.js` moves the 800–1,200 count.
6. `assets` is empty in CNT-1, so only `CNT-1-preview.png` is servable.
7. No accessibility audit (axe/screen reader) and no automated visual regression.
8. `X-Robots-Tag: noindex, nofollow` is set on article responses as an anti-indexing safeguard.
