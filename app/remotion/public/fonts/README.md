# ACE Thai font pack

วางไฟล์ฟอนต์ที่มีสิทธิ์ใช้งานในโฟลเดอร์นี้ โดยใช้ชื่อไฟล์ตาม manifest ใน
`../src/fonts.css` เช่น:

- `NotoSansThai-Regular.woff2`
- `NotoSansThai-Medium.woff2`
- `NotoSansThai-Bold.woff2`

ห้ามคัดลอกฟอนต์จาก `C:\Windows\Fonts` มาแจกจ่ายโดยไม่ตรวจสอบ License
ฟอนต์ระบบ Windows ใช้ดู Preview ในเครื่องได้ แต่ Render ต้องใช้ไฟล์ฟอนต์ที่
โปรเจกต์มีสิทธิ์ฝังและแจกจ่ายได้อย่างถูกต้อง

หลังเพิ่มไฟล์จริง ให้ตรวจทั้ง Remotion Studio และ MP4 ที่ Render แล้วว่า:

1. สระและวรรณยุกต์ไม่ลอยหรือชนกัน
2. การตัดบรรทัดภาษาไทยเหมาะสม
3. Preview และ Render แสดงผลเหมือนกัน
