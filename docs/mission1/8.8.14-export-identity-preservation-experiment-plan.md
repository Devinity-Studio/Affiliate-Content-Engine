## 3. Required Terminology

Use these distinctions precisely:

- **File metadata:** path, filename, size, and hash.
- **Export identity:** a distinct identity for an individual export; do not claim one exists unless evidence supports it.
- **Version-derived filename:** current filename derived from `content_id` and `script_version`.
- **Hash Calculation:** calculating a file's SHA-256.
- **Hash Recording:** storing the calculated hash in a record.
- **Hash Verification:** independently checking that the file's actual hash matches the expected or recorded hash.

Do not treat these three hash operations as interchangeable.

## 4. Experiment Cases

### E1 — Re-export without changing Script Version
Determine whether:
- the output filename remains the same;
- the existing MP4 is overwritten;
- the still frame is overwritten;
- the Library record is replaced or retained;
- the previous file remains recoverable.

### E2 — Re-export after changing Script Version
Determine whether:
- the output filename changes;
- the previous MP4 remains;
- the previous still frame remains;
- both exports remain represented in the Library;
- the records can be distinguished and traced to their source version.

### E3 — Hash behavior
Determine separately whether the current implementation:
- calculates SHA-256;
- records SHA-256;
- independently verifies the written file against an expected or recorded hash.

Do not infer verification merely from the presence of a hash field.

## 5. Experiment Safety

5. Use synthetic or copied test data.
6. Execute experiments and capture actual outputs.

If any step risks modifying original data, stop.

## 6. Evidence Classification

Every finding must be classified as one of:

- **Code Evidence:** behavior visible in inspected source.
- **Actual Experiment Result:** behavior observed from a successfully executed experiment.
- **Expected Observation:** predicted behavior not yet executed.
- **Not Tested:** no experiment was run.
- **Unknown:** evidence is insufficient.

Never present Expected Observation or Not Tested as an actual result.
