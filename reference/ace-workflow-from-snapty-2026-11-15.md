## 3) สิ่งที่ ACE ทำ "ละเอียดกว่า" SnapYT (จุดขาย)

1. **ข้อมูลจริงทุกฟิลด์ต่อการ์ด** — ราคา, ค่าคอม % และ ฿, ยอดขาย, ร้าน, shopId/itemId (กันซ้ำ), ลิงก์ข้อเสนอผูกการ์ดทันที
2. **CTA ต่อสินค้า** (ใหม่) — ไม่ใช่ CTA เดียวทั้งโปรไฟล์; ใช้แทนได้ในสคริปต์ AI ต่อสินค้า
3. **Sub_id ต่อช่องทาง (5 ช่อง)** — แยกแคมเปญ/แพลตฟอร์มเพื่อวัดผลจริง
4. **AI Shortlist พร้อมเหตุผล/ความเสี่ยง/hook** — คัดจากข้อมูลจริง ไม่เดาราคา/โปร
5. **Prompt Pack ต่อสินค้า** (จะทำ) — รวมคำสั่งภาพ/วิดีโอ + CTA + แคปชัน พร้อมคัดลอกไปเครื่องมือเจนนอกระบบ
6. **Audit trail** — ทุก AI call มี trace (provider/model/latency) + provenance
7. **Multi-provider** — OpenRouter / OrcaRouter (ฟรี) / Gemini เลือกได้ทั้งระบบหรือต่อขั้น

## 4) Roadmap ที่เสนอ (เรียงตามความคุ้มค่า)

- **Phase 2 (ถัดไป)**: รูปสินค้า 3–5 รูปต่อการ์ด (gallery + เลือกภาพหลัก) + "Prompt Pack" ต่อสินค้า (คัดลอกชุดคำสั่งไปเจนภาพ/วิดีโอ) + CTA ต่อช่องทาง
- **Phase 3**: "Automation Bundle" export — JSON/CSV ตรงสเปกฟอร์มภายนอก (วันที่, รูป 3–5, รายละเอียด, CTA, ลิงก์) เพื่อส่งเข้า automation ของผู้ใช้ โดยคง governance: ACE ไม่โพสต์เองอัตโนมัติ
- **Phase 4**: นำเข้า CSV รายงานผลจาก Shopee (คลิก/ยอดขาย/ค่าคอม) ผูกกับ candidate → Dashboard/Report จริง + ปรับ Shortlist ด้วยผลจริง
- **Phase 5 (ออปชัน)**: per-step provider routing UI (backend พร้อมแล้ว), template วิดีโอหลายสไตล์, ตารางโพสต์รายสัปดาห์

## 5) ขอบเขตที่ยังคงเดิม (ไม่ล้ำเส้น)

- ไม่ล็อกอิน/ไม่เก็บ cookie Shopee; ไม่ใช้ Shopee Open API (ยังไม่มีสิทธิ์)
- ไม่เจนภาพ/วิดีโอในระบบ; ไม่โพสต์อัตโนมัติ (manual publish + queue)
- คีย์/provider เก็บใน memory เซิร์ฟเวอร์เท่านั้น (แนะนำใส่ `.env` เพื่อความถาวร)
